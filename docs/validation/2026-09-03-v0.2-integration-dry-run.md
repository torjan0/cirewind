## Boundaries

This record proves mergeability and gate behavior of the combined source at
one moment. It establishes no human review, no pack approval, no lab
reproduction, no release readiness, and it becomes stale as soon as any branch
moves. The integration branch is a preview for the maintainer's convenience,
not a substitute for merging the pull requests in the order above.
